#  TrabajoYa - Full Stack

Plataforma de gestión de empleos desarrollada para el 7mo semestre de Ingeniería de Sistemas.

##  Arquitectura
El proyecto utiliza **Clean Architecture** para separar la lógica de negocio de la infraestructura:
- **Domain:** Entidades y reglas de negocio.
- **Application:** Casos de uso.
- **Infrastructure:** Repositorios y controladores HTTP (Express).

##  Tecnologías
- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Control de Versiones:** Git + GitHub

##  Cómo ejecutar
1. **Backend:** `cd backend && node index.js`
2. **Frontend:** `cd frontend && npm run dev`
